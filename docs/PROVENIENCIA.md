# Provenance / Origem dos componentes

[English](#english) · [Português](#português)

## English

The component origins were checked on **2026-10-21** by comparing the installed files with upstream sources. This is a summary of the [machine-readable evidence](PROVENIENCIA.json); full attribution and license details are in [credits](../CREDITOS.md).

- **Icons:** Gruvbox Plus by SylEleuth and contributors, using the original Gruvbox palette by Pavel Pertsev (morhetz).
- **GTK/Cinnamon base:** Fausto-Korpsvart's Gruvbox GTK Theme, based on Vince Liuice. Historical revision `c0b7fb501938241a3b6b5734f8cb1f0982edc6b4` has 251 matching regular files; Cinnamon CSS differs.
- **MOD variant:** Twilight4/gnome-settings revision `5560f12a465654d1808638ccb4e6e0968ac10240` has 255 matching entries. Historical CSS modifications have not all been attributed to individual authors.
- **Cursor:** Capitaine Cursors (Gruvbox) – White r5, from sainnhe/capitaine-cursors. All 113 files match. Keefer Rourke authored original Capitaine; sainnhe added Gruvbox.

Original license notices are preserved in [LICENSES](../LICENSES/). A matching collection establishes a source of distribution, not authorship of every modification. Unknown work is not attributed to Pir or OpenAI Codex.

## Português

As origens foram conferidas em **21/10/2026** pela comparação dos arquivos instalados com as fontes originais. Este é um resumo das [evidências estruturadas](PROVENIENCIA.json); as atribuições e licenças completas estão nos [créditos](../CREDITOS.md).

- **Ícones:** Gruvbox Plus, de SylEleuth e colaboradores, usando a paleta Gruvbox original de Pavel Pertsev (morhetz).
- **Base GTK/Cinnamon:** Gruvbox GTK Theme de Fausto-Korpsvart, baseado em Vince Liuice. A revisão histórica `c0b7fb501938241a3b6b5734f8cb1f0982edc6b4` tem 251 arquivos regulares iguais; o CSS do Cinnamon difere.
- **Variante MOD:** a revisão `5560f12a465654d1808638ccb4e6e0968ac10240` de Twilight4/gnome-settings tem 255 entradas iguais. Nem todas as alterações históricas de CSS têm autoria individual identificada.
- **Cursor:** Capitaine Cursors (Gruvbox) – White r5, de sainnhe/capitaine-cursors. Os 113 arquivos coincidem. Keefer Rourke criou o Capitaine original; sainnhe acrescentou a variante Gruvbox.

Os avisos originais estão em [LICENSES](../LICENSES/). Uma coleção coincidente comprova uma origem de distribuição, não a autoria de toda modificação. Trabalho de autoria desconhecida não é atribuído a Pir ou OpenAI Codex.
